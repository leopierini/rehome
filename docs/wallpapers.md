# Wallpapers

The six wallpapers built into the launcher are free-licence photos from Unsplash, taken from their Wikimedia Commons
copies, where they are published under CC0 1.0 (public domain dedication); the Unsplash License allows the same free
use. Changes for the TV, for all six: cropped to 16:9, scaled to 1920×1080, re-encoded as JPEG (quality 84) with all
metadata removed; further changes are noted per picture. The launcher also darkens them on screen (`wallpaper_dim`,
55 %) and draws a vignette; that is not in the files.

The files are in `app/src/main/res/drawable-nodpi/`. To use your own pictures instead, see
[Wallpapers and themes](guide.md#wallpapers-and-themes) in the guide.
